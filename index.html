Prepare

Ink is the truth

If the preview lies, that is a bug. Every line on screen is drawn at the width of the pen that will draw it, so what you approve is what the plotter makes.

True pen width
A 0.3 mm fineliner and a 0.8 mm marker make different pictures. You see which one before the pen touches the paper.
Ink-risk heatmap
Amber where the ink nears what the paper takes, red where it is over. Thin the drawing or change the paper before it bleeds.
Time estimate
How long the job runs on your machine, pen by pen, before you start it.
Path optimisation
Strokes are reordered so the pen spends its time drawing. On a cross-hatched A4 portrait, pen-up travel fell from 14.3 m to 2.2 m.
Pen refresh
A pen that has drawn its rated distance is paused for a swap or sent to dip, between two strokes and never mid-line.

Ink limits are estimates until you measure your own pens and papers. TerraGen says so wherever it reports a risk.

Create

Simple on top, infinite underneath

Every style in the carousel is a saved node graph. If you never open it, you never need to know. If you do, you can change anything.

Node graph
Sources, fields, generators and pen layers as nodes. Rewire a style, then save it as one of your own and use it as a node in the next.
Fields
Bind a slider to the picture. Tone, noise, gradient or depth can drive spacing, angle or weight, point by point across the page.
Live sliders
Each parameter has a range, a unit and a sensible default. Move one and the page is drawn again.
The same lines every time
The same project and seed draw the same lines on every computer, so a piece can be plotted again years later.

The code workspace

Write JavaScript and watch the page redraw as you type. A comment after a constant turns it into a slider. This is the whole of Noise rings, one of the built-in styles: 

const rings = 36;    // min=3, max=100, step=1, How many rings
const amount = 14;   // min=0, max=40, step=0.5, How far noise pushes a ring
const grain = 1.1;   // min=0.2, max=3, step=0.05, Bumps round a ring
const drift = 0.06;  // min=0, max=0.3, step=0.005, Change from ring to ring
const hole = 0.12;   // min=0, max=0.6, step=0.01, Size of the empty middle
const stretch = 1;   // min=0.4, max=1.6, step=0.05, Width against height

const cx = page.x + page.width / 2;
const cy = page.y + page.height / 2;
const reach = Math.min(page.width, page.height) / 2 - 4 - amount;

for (let i = 0; i < rings; i++) {
  const base = reach * (hole + ((1 - hole) * (i + 1)) / rings);
  const points = [];
  for (let s = 0; s < 180; s++) {
    const a = (s / 180) * 2 * Math.PI;
    const n = noise(Math.cos(a) * grain + 20 + i * drift,
                    Math.sin(a) * grain + 20 + i * drift);
    const r = base + amount * n * (0.3 + (0.7 * (i + 1)) / rings);
    points.push([cx + r * stretch * Math.cos(a), cy + r * Math.sin(a)]);
  }
  polyline(points, true);
}

Plot

From the screen to the pen

TerraGen drives terraPen and other machines that run FluidNC or GRBL. Bring yours in from its own settings file.

Wi-Fi upload
Send the job to a FluidNC machine's SD card over your own network and start it from TerraGen.
Live progress
Watch where the pen is in the drawing. Pause, resume or stop.
Resume a stopped job
A pen ran dry or the power went. Plot the rest from the stroke it reached.
One G-code file per pen
A drawing in three pens is three files, in plotting order, each checked against the bed.
Nothing moves unasked
Every upload and every plot asks first. Trace the job with the pen up before you commit ink.

Publish Pro

A signed edition of 25, ready for the fair

Publish turns one drawing into work you can sell. Every piece is numbered, signed and certified, and pictured framed for the listing without a camera.

  • Editions

    Set the size and how the pieces vary. Piece 3 of 50 is the same drawing on every computer, this year and next.

  • Signature and title block

    Sign once with a mouse or a tablet. It is plotted as a single line under every piece, and kept on your computer.

  • Certificates of authenticity

    One per piece, with its seed, machine, paper and pens, and a hash a buyer can check.

  • Proof sheets

    A contact sheet of variants with their seeds, for a client to choose from before you ink anything.

  • Framed mockups

    Square, portrait or wall-wide. Oak, walnut, black or white. Four walls. Ready for a listing.

  • CSV batch

    Two hundred wedding maps from one spreadsheet: a row is a piece, with its own names, date and place.

  • Costing and quotes

    Machine time, ink, paper and frame add up to a price, and to a one-page quote for a commission.

  • Borders

    A plotted border on a pen of its own, set by its margin from the drawing or by its size.
